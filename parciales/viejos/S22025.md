En esta evaluación se busca modelar un chequeo de tipos sobre expresiones de un
lenguaje que opera sobre números y texto. Se define un tipo Exp para modelar expresiones
de un lenguaje de programación, un tipo TType para modelar los tipos de dichas
expresiones, y un tipo Value que modela los posibles valores resultantes de reducir a las
expresiones modeladas.

data TType = Number | Boolean | Text
type Variable = String
data Exp
    = LNum Int                                         -- Literal numérico
    | LText String                                      -- Literal de texto
    | Var Variable                                     -- Variable de tipo texto
    | AritOp (Int->Int->Int) Exp Exp          -- Operaciones aritméticas sobre números
    | RelOp  (Int->Int->Bool) Exp Exp      -- Operaciones relacionales sobre números
    | TextAritOp (String->String) Exp        -- Operaciones texto a texto
    | TextNumOp  (String->Int) Exp           -- Operaciones texto a número

data Value = VInt Int | VBool Bool | VText String | TypeError

Se define además un tipo Cmd para modelar un lenguaje imperativo simple que utiliza estas
expresiones.

data Cmd
    = Skip                                               -- statement que no hace nada
    | StoreInput Variable String              -- recuerda texto literal en la variable dada
    | PrintVar Variable                            -- imprime el valor de una variable
    | Seq Cmd Cmd                               -- secuencia de comandos
    | If Exp Cmd Cmd                            -- alternativa entre dos comandos

data State = S (Variable->String) [String]
    --           memoria de variables stdout

Ejercicios

1. Definir por recursión explícita las siguientes funciones

a. typecheck :: Exp -> Maybe TType, que dada una expresión, determina su tipo, si el mismo
es correcto. Las operaciones tienen tipo correcto cuando se aplican a los argumentos del
tipo que corresponde, y dan como resultado el tipo que indica qué es el resultado.
   EJEMPLOS:
   * typecheck (AritOp (+) (LNum 2) (LText "Hola")) = Nothing
   * typecheck (RelOp (>) (LNum 2) (LNum 3)) = Just Boolean

b. evalExp :: Exp -> (Variable->String) -> Value, que dada una expresión y un valor para
   cada variable (como función total), evalúa el valor que corresponde: si la expresión no
tiene tipo válido, da el valor TypeError y si no da el resultado correspondiente como
elemento de tipo
   Value.
   EJEMPLOS:
   * evalExp (AritOp (+) (LNum 2) (LText "Hola")) baseEnv = TypeError
   * evalExp (RelOp (>) (LNum 2) (LNum 3)) baseEnv = VBool False

a. simplifyCmd :: Cmd -> Cmd, que describe un comando equivalente al dado, pero que no
